Krayolin — Do You Forgive Me? HD Website

This build is a self-contained, mobile-friendly romantic micro-site.

Files are intentionally kept together in one folder:
- index.html
- style.css
- script.js
- icon.svg
- forgive-question-hd.webp
- forgive-result-hd.webp

The supplied illustrations were upscaled and lightly sharpened for cleaner HD presentation, then optimized as WebP for fast loading.

To run:
1. Keep all files together.
2. Open index.html in a modern browser.

For local hosting, any simple static server will also work.
